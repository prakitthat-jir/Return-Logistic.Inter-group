☁️ ซิงค์ข้อมูลข้ามเครื่อง (Firebase) ใช้ลิงก์เดียวกัน · ข้อมูลแชร์กันแบบเรียลไทม์
ตั้งครั้งเดียว แล้วทุกเครื่องที่เปิดลิงก์เดียวกันจะเห็น/แก้ข้อมูลชุดเดียวกัน:
  1. ไป console.firebase.google.com → สร้างโปรเจกต์ (ฟรี)
  2. เมนู Build → Firestore Database → Create database (Production/Test ก็ได้)
  3. เมนู Build → Authentication → Sign-in method → เปิด Anonymous
  4. ⚙️ Project settings → Your apps → Web (</>) → คัดลอกก้อน firebaseConfig มาวางด้านล่าง
🔒 firebaseConfig ไม่ใช่รหัสลับ แต่ลิงก์แอปจะเขียน/อ่านฐานข้อมูลได้ — ควรตั้ง Firestore Rules ให้เฉพาะผู้ล็อกอิน (anonymous) และอย่าเผยแพร่ลิงก์ออกนอกทีม
